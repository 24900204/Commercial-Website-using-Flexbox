# Commercial-Website-using-Flexbox


## Aim

To design and develop a responsive commercial website using CSS Flexbox with a navigation bar, product section, offers, and footer.

## Procedure
Fork the given GitHub repository.
Clone the repository to the local system.
Create the required HTML/React structure.
Create CSS styles using Flexbox.
Design the responsive navigation bar.
Create the hero and product sections.
Add product cards with prices and buttons.
Add the offers and information sections.
