# FlexMart — Commercial Website using CSS Flexbox

## Ex.02 Case Study
A responsive commercial website developed to demonstrate **CSS Flexbox** for a clean, flexible and mobile-friendly layout.

### Features
- Responsive navigation bar
- Hero/banner section
- Product cards arranged with Flexbox and wrapping
- Offer section
- Responsive feature strip
- Shopping cart interaction
- Responsive footer
- Student Name and Register Number in footer

### Technologies
- HTML5
- CSS3 Flexbox
- React
- Vite

### How to Run
```bash
npm install
npm run dev
```

Open the local URL shown by Vite in the terminal.

### Important
Before submission, edit `src/main.jsx` and replace:
- `YOUR NAME`
- `YOUR REGISTER NUMBER`

with your actual details.

## Working Principle
The website uses Flexbox containers for navigation, hero content, feature items, product cards, offer content and footer columns. `flex-wrap`, flexible widths, gaps and media queries allow the layout to rearrange automatically on tablets and mobile devices. Product cards are added to a demo cart using React state.
