## Project Description
A responsive Simple Calculator developed using React. It supports basic arithmetic operations and demonstrates React state management and event handling.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Decimal numbers
- Positive/negative toggle
- Backspace
- All Clear
- Memory functions: MC, MR, M+, M−
- Responsive design
- Student details displayed in the footer

## Technologies Used
- HTML5
- CSS3
- React
- Vite
- JavaScript

## How to Run
Open the project folder in a terminal and run:

```bash
npm install
npm run dev
```

Open the local URL displayed by Vite.

## Working Principle
The calculator uses React `useState` to store the current display, expression and memory value. Button clicks call event-handler functions that update the state. When an arithmetic operator is selected, the first number and operator are stored. Pressing `=` performs the selected operation and updates the display. CSS Grid is used for the calculator keypad, while responsive CSS adapts the page for smaller screens.
